# 📊 Data Jobs Dashboard with Power BI

An interactive **Power BI dashboard** designed to explore the 2024 data job market, focusing on **job demand, salaries, job types, locations, platforms, and individual job roles**.

The project transforms raw job-posting data into an interactive dashboard that helps **job seekers, career switchers, and data professionals** understand market trends and compensation.

---

## 📌 Project Overview

![Home Dashboard](/images/Home.png)

Finding useful information about data-related jobs can be difficult because job postings are spread across different platforms and contain a large amount of information.

This project brings key information from **2024 data science and data-related job postings** into a single interactive Power BI dashboard.

The dashboard allows users to:

- Explore the overall data job market
- Compare job counts across different roles
- Analyze yearly and hourly salaries
- Identify the most in-demand data roles
- Explore the global distribution of data jobs
- Analyze job-posting platforms
- Examine different job types
- Drill through into individual job titles for detailed insights

---

## 🎯 Objectives

The main objectives of this project are to:

1. Understand the demand for different data-related job roles.
2. Analyze salary trends across data jobs.
3. Compare annual and hourly compensation.
4. Identify job titles with the highest number of postings.
5. Understand the geographical distribution of data jobs.
6. Explore the platforms used to advertise job postings.
7. Build an interactive dashboard for exploring individual job roles.

## 🏁 Conclusion

This project demonstrates how **Power BI can be used to transform raw job-posting data into an interactive and meaningful business intelligence dashboard**.

By combining data cleaning with Power Query, analytical calculations using DAX, and interactive visualizations, the dashboard provides a clear view of the **2024 data job market**. Users can explore job demand, salary trends, geographic distribution, job types, and hiring platforms, while the drill-through functionality allows for deeper analysis of individual job roles.

Overall, this dashboard provides a practical example of how **data analytics, visualization, and business intelligence can be combined to turn large datasets into actionable insights for job seekers and data professionals**.
